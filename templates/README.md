# Templates

**Last updated:** September 26, 2026

Starter files for every new project. Copy them in, then fill in the brackets.

- **[Home.md](Home.md):** the project Dashboard. Hypothesis, problem to solve, and what success looks like sit at the top. Goes in `docs/wiki/Home.md`.
- **[CLAUDE.md](CLAUDE.md):** the first file Claude reads in a repo. The project in one line, its rules, and where everything lives.
- **[voice.md](voice.md):** how the project sounds, for each audience. Goes in `docs/voice.md`.
- **[Documents.md](Documents.md):** every document in the repo and when to open it. Goes in `docs/wiki/Documents.md`.
- **[publish-wiki.yml](publish-wiki.yml):** publishes `docs/wiki/` to the GitHub wiki tab on every merge. Goes in `.github/workflows/`.
