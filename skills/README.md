# Skills

**Last updated:** September 26, 2026

Read-only copies of the custom Claude skills that guide my work. The working versions live in my Claude account; these copies are updated whenever a skill changes.

Each skill reviews itself after use and suggests improvements, which I approve. The change log at the end of each file shows how it has grown.

- **[product-project-manager](product-project-manager/SKILL.md):** plans problem-first. A roadmap readable in 3 seconds, a researched backlog, milestones, risks and decisions. Based on Marty Cagan's *Inspired*, and written for ADHD and neurodivergent readers.
- **[product-designer](product-designer/SKILL.md):** designs and reviews screens, pages and components. My principles first, then UX laws, heuristics, information architecture, WCAG 2.2, and AI and agentic design. Gates what enters the component library.
- **[content-writer](content-writer/SKILL.md):** writes and reviews every word people read. Show first, as few words as clarity allows, respectful and a little fun. Each project sets its voice in a voice file.
- **[portfolio-frontend-build](portfolio-frontend-build/SKILL.md):** moves a prototype built in Claude artifacts into a real repo, then rebuilds it as clean, tested code with design tokens, Storybook and a Figma loop.
